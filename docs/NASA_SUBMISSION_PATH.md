# NASA submission path

**Checked:** 2026-08-27
**Status:** planning document; no NASA program element has been selected and no submission is
authorized by this repository.

AstroBridge should not be emailed to NASA as a repository link and described as a proposal.
NASA science research is normally submitted against a specific solicitation through NSPIRES,
by an eligible organization and its Authorized Organizational Representative (AOR).

## Current route assessment

- NASA's funding page currently points researchers to ROSES and the individual program
  elements and due dates in NSPIRES. The exact live table must be checked again immediately
  before proposal work starts.
- The 2026 deadline announced for the ROSES-25 D.6 Astrophysics Research and Analysis Program
  (APRA) was 2026-08-06, so that opportunity is already closed as of this review.
- A newly posted opportunity is not automatically a fit. AstroBridge needs a program element
  whose science scope explicitly covers archival astrophysics, catalog methodology, or a
  relevant NASA mission-data objective.
- NASA states that most proposals are solicited. An unsolicited proposal is an exceptional
  route for work that does not fit a current solicitation, not a shortcut around peer
  competition or a missed deadline.

## Eligibility constraint for a Brazil-based independent contributor

NASA's current SARA FAQ states that NASA funds research at U.S. institutions and that work at
non-U.S. organizations is generally cooperative on a no-exchange-of-funds basis. A foreign
collaborator may be named on a proposal from a U.S. organization, but NASA funds generally may
not support the foreign organization's research or travel unless the exact solicitation says
otherwise.

The practical default route is therefore:

1. find a scientifically aligned U.S. university, nonprofit, company, or other eligible
   institution;
2. agree on scientific ownership, authorship, data governance, and a no-exchange-of-funds or
   separately funded role;
3. have that institution confirm eligibility and submit through its AOR in NSPIRES; and
4. verify every exception and budget rule in the selected program element.

This is planning guidance, not a legal eligibility determination. The program officer and the
submitting institution's research office must confirm the final interpretation.

## Go/no-go gates

Do not start a full NASA proposal until all gates in a row are satisfied.

| Gate | Evidence required | Current state |
|---|---|---|
| Scientific claim | External association truth set plus held-out sky fields | No-go |
| Calibration | Reliability curve, Brier score, density/magnitude strata, prior sensitivity | No-go |
| Reproduction | Scripted data manifests, query timestamps, checksums, tables, and figures | No-go |
| Archival record | Versioned release and DOI, including required inputs/configuration | No-go |
| Program fit | Named live program element and paragraph-by-paragraph scope mapping | No-go |
| Eligibility | Eligible submitting organization, PI/AOR, and confirmed foreign role | No-go |
| Team review | Astronomer with catalog cross-identification expertise | No-go |

## Submission sequence

1. Complete the scientific gates above and obtain independent review.
2. Recheck the NASA funding page and NSPIRES table; record the solicitation number, program
   element, version/amendment, due date, and program officer.
3. Read the complete program element and ROSES summary, not only the web announcement.
4. Create a compliance matrix for eligibility, page limits, anonymization, budget, data
   management, software sharing, and required forms.
5. Map each AstroBridge objective to a NASA mission-data return or an explicit program goal.
6. Register every team member in NSPIRES and confirm the submitting organization's AOR
   workflow well before the deadline.
7. Ask only scope or eligibility questions not answered by the solicitation, using the named
   program officer or SARA contact.
8. Prepare an Open Science and Data Management Plan. Archive the release in a repository that
   issues a DOI; GitHub alone is not the archival record.
9. Release the proposal to the organization early enough for the AOR to submit it in NSPIRES.
10. Preserve the submitted package, solicitation version, confirmations, and resulting review
    correspondence in the project's private records.
