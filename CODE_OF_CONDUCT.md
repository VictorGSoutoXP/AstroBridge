# AstroBridge Code of Conduct

AstroBridge welcomes scientific criticism, replication attempts, bug reports, and
contributions from people of every background and level of experience.

Participants are expected to:

- discuss methods, evidence, and code without personal attacks;
- state uncertainty and distinguish demonstrated results from hypotheses;
- credit data providers, publications, and contributors accurately;
- avoid harassment, discrimination, intimidation, and disclosure of private information;
- report security or privacy-sensitive problems privately rather than publishing them.

Project maintainers may edit or remove contributions that violate these expectations and
may temporarily or permanently restrict participation when necessary to protect the
community.

Concerns may be reported to Victor Gonçalves Souto at
victor@soutoconsultoria.com.br. Reports will be handled as confidentially as practical.

This code applies to the repository, issue tracker, pull requests, project communications,
and events where someone represents AstroBridge.
